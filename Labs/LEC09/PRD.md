# 소닉 애니메이션 뷰어 PRD

> 근거 문서: [PRE-PRD.md](PRE-PRD.md)

## 1. 개요

`sonic-sprite.png` 스프라이트 시트에 들어 있는 소닉 애니메이션을 동작별로 차례대로 재생하는 뷰어를 만든다.

| 항목              | 내용                                                          |
| ----------------- | ------------------------------------------------------------- |
| 언어 / 라이브러리 | Python, pico2d                                                |
| 파일              | `Labs/LEC09/sonic_animation_viewer.py` (단일 파일)          |
| 리소스            | `Labs/LEC09/sonic-sprite.png` (399 × 525, RGBA, 배경 투명) |
| 브랜치            | `LEC09-animation-viewer`                                    |
| 실행 위치         | `Labs/LEC09` 폴더 안에서 실행 (이미지를 상대 경로로 불러옴) |

## 2. 기능 요구사항

| ID | 요구사항                                                                    |
| -- | --------------------------------------------------------------------------- |
| F1 | 스프라이트 시트에 있는**모든** 소닉 애니메이션(14개 동작)을 재생한다. |
| F2 | 한 동작의 애니메이션은**5번 반복** 재생한다.                          |
| F3 | 5번 반복이 끝나면**1초 쉬고** 다음 동작으로 넘어간다.                 |
| F4 | 마지막 동작이 끝나면 첫 동작부터 다시 재생한다(무한 반복).                  |
| F5 | 캐릭터를 화면에서 잘 보이도록**확대**해서 그린다.                     |
| F6 | 창 닫기 버튼이나`ESC` 키로 프로그램을 끝낼 수 있다.                       |
| F7 | 이동이 포함된 동작(걷기, 달리기 등)은 캐릭터가 **실제로 화면에서 이동**한다. |

### 상세 동작

- **프레임 간격:** 0.1초
- **쉬는 1초 동안:** 마지막 프레임을 화면에 그대로 둔다.
- **확대 배율:** 5배. 시트의 프레임은 가장 큰 것이 39 × 45 픽셀로 아주 작다. 5배로 하면 최대 195 × 225가 되어 1200 × 800 화면에서 잘 보인다.
- **그리는 위치:** 프레임의 중심을 **화면 정중앙**에 맞춘다.
  - x = 600 (CANVAS_W / 2)
  - y = 400 (CANVAS_H / 2)
  - 프레임마다 높이가 달라서 동작에 따라 발 위치가 조금씩 위아래로 달라질 수 있다.
- **이동:** 이동이 포함된 동작은 제자리에서 재생하면 어떤 동작인지 알아보기 어렵다. 그래서 동작마다 정한 **이동 속도**(픽셀/초)로 캐릭터를 오른쪽으로 움직인다.
  - y는 화면 정중앙(400) 그대로 두고 x만 바뀐다.
  - 동작이 시작될 때 x를 화면 가운데(600)로 되돌린다. 제자리 동작은 속도가 0이라 항상 가운데에 있다.
  - 프레임은 0.1초마다 바뀌지만, 위치는 약 0.01초마다 갱신해서 부드럽게 움직인다.
  - 캐릭터가 화면 오른쪽 밖으로 완전히 나가면 왼쪽 밖에서 다시 들어온다.
  - 쉬는 1초 동안은 멈춘 위치에 마지막 프레임을 그대로 둔다.
- **반응성:** 기다리는 동안에도 매 프레임 `handle_events()`를 불러서 창이 "응답 없음"이 되지 않게 한다. 쉬는 1초도 짧은 간격으로 나눠서 기다리며 이벤트를 처리한다.

## 4. 코드 구조

```
sonic_animation_viewer.py
├─ 상수          CANVAS_W, CANVAS_H, SCALE, FRAME_TIME, REPEAT_COUNT, PAUSE_TIME
├─ 프레임 데이터   idle, crouch, walk, ... look_around (3장 좌표)
├─ ANIMATIONS    [('Idle', idle, 0), ('Walk', walk, 150), ..., ('Look Around', look_around, 0)]  (이름, 프레임, 이동 속도)
├─ char_x        캐릭터의 현재 x 위치
├─ handle_events()                   닫기 / ESC → running = False
├─ draw_frame(frame)                 clear → clip_draw((char_x, 화면 세로 가운데), SCALE배) → update
├─ wait(seconds)                     짧게 나눠 delay 하면서 handle_events
├─ move_character(frame, speed, dt)  char_x += speed × dt, 화면 오른쪽 밖으로 나가면 왼쪽 밖으로
├─ play_animation(frames, speed)     프레임마다 FRAME_TIME 동안 이동하며 다시 그리기
├─ play_action(name, frames, speed)  char_x 가운데로 → play_animation × REPEAT_COUNT → wait(PAUSE_TIME)
└─ 메인 루프                          running 동안 ANIMATIONS 순서대로 play_action → close_canvas()
```

| 상수                       | 값       |
| -------------------------- | -------- |
| `CANVAS_W`, `CANVAS_H` | 1200, 800 |
| `SCALE`                  | 5        |
| `FRAME_TIME`             | 0.1      |
| `REPEAT_COUNT`           | 5        |
| `PAUSE_TIME`             | 1.0      |

`running`이 `False`가 되면 재생 중이던 반복문들도 바로 빠져나와서 프로그램이 끝나야 한다.

전체 한 바퀴는 약 52초다(76프레임 × 0.1초 × 5번 + 14동작 × 1초).
